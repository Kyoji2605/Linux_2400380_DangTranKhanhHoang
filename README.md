## 2. Giới thiệu
Bài thực hành sử dụng Ubuntu Linux, Bash Script,
Git và GitHub.

## 3. Chức năng các chương trình
- hethong.sh: Kiểm tra thông tin hệ thống và kết nối mạng.
- quanlysv.sh: Quản lý danh sách sinh viên.
- saoluu.sh: Sao lưu dữ liệu và ghi nhật ký.

## 4. Hướng dẫn sử dụng

Cấp quyền thực thi:

chmod +x scripts/*.sh

Chạy kiểm tra hệ thống:

bash scripts/hethong.sh

Chạy quản lý sinh viên:

bash scripts/quanlysv.sh

Chạy sao lưu:

bash scripts/saoluu.sh
